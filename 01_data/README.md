\# Dataset Information



\## Online Retail II



This project uses the \*\*Online Retail II\*\* dataset from the UCI Machine Learning Repository.



\### Dataset Details



\- \*\*Source:\*\* UCI Machine Learning Repository

\- \*\*Dataset:\*\* Online Retail II

\- \*\*Business:\*\* UK-based online gift retailer

\- \*\*Period:\*\* December 2009 – December 2011

\- \*\*Original size:\*\* 1,067,371 transaction records

\- \*\*Currency:\*\* British Pound Sterling (GBP)



\### Data Description



The dataset contains transactional information, including:



\- Invoice number

\- Product stock code

\- Product description

\- Quantity

\- Invoice date

\- Unit price

\- Customer ID

\- Country



\### Download



The original dataset can be obtained from:



https://archive.ics.uci.edu/dataset/502/online+retail+ii



\### Usage in This Project



The original dataset was imported into Power BI and processed using Power Query (M).



The cleaning process included handling cancelled transactions, invalid quantities and prices, non-product entries, and duplicate records.



The cleaned sales data and separate returns table were then used to develop the interactive Power BI dashboard and perform customer segmentation.



\*\*Note:\*\* The original CSV file is not included in this repository. Please download it directly from the official UCI source.
